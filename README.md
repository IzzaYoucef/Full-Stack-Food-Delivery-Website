# Full-Stack Food Delivery Website

A full-stack food delivery web application built with the MERN stack (MongoDB, Express.js, React.js, and Node.js) to strengthen my web development skills and gain hands-on experience in building real-world applications.

## Project Development Roadmap

- **Food Cart Management:** Implemented add-to-cart and remove-from-cart functionality using React's `useState()` and `useContext()` hooks to manage food items and cart state. Added CSS styling to improve the user experience.
- **Responsive Frontend:** Developed a responsive home page and implemented user sign-up and sign-in interfaces.
- **Cart and Checkout:** Built responsive cart and order placement pages, including item quantity management and price calculations.
- **Admin Dashboard:** Created an admin panel to upload new food items and display the list of available products.
- **Backend Development:** Set up the Node.js and Express.js backend, connected MongoDB, and implemented the food model, controllers, and API routes. Integrated the backend with the frontend.
- **User Authentication:** Implemented user registration and login functionality, including JWT-based authentication, and integrated it with the frontend.
- **Order Management:** Developed functionality to store customer orders in the database and connected the order placement process to the backend.
- **Order Tracking and Administration:** Implemented order history for users, order management in the admin panel, and delivery status updates.
- **Payment Integration:** Worked on resolving payment processing issues to ensure a smoother checkout experience.

**Technologies:** MongoDB, Express.js, React.js, Node.js, JavaScript, HTML, CSS, REST APIs, JWT.
